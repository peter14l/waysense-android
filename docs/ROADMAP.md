- [x] Disruption simulation
- [x] Accessibility settings

- [x] Help screen

## Phase 2: Enhanced UX

- [ ] Persist onboarding completion (DataStore)
- [ ] Persist accessibility preferences
- [ ] Real Android TTS integration (optional, graceful fallback)
- [ ] Real vibration patterns using VibrationEffect API
- [ ] Improved onboarding with accessibility profile import
- [ ] Dark mode toggle in app (independent of system)
- [ ] Haptic feedback for navigation steps

## Phase 3: Real Data Integration

- [ ] Google Maps SDK integration
- [ ] Google Directions API for routing

- [ ] GPS-based location tracking

- [ ] Community-contributed accessibility reports

## Phase 4: Intelligence

- [ ] Machine learning for station recognition (camera)
- [ ] Predictive route suggestions based on history
- [ ] Smart disruption prediction
- [ ] Personalized accessibility profile learning
- [ ] Voice command navigation ("Take me to Esplanade")

## Phase 5: Platform

- [ ] Multi-language support (Hindi, Bengali, English)
- [ ] Widget for quick journey status
- [ ] Wear OS companion for wrist-based guidance
- [ ] Integration with hearing aid Bluetooth

---

## Phase 6: Community

- [ ] User-contributed accessibility ratings
- [ ] Crowdsourced disruption reporting
- [ ] Peer navigation assistance
- [ ] Integration with local transit authority feedback systems
- [ ] Open data API for accessibility information

---

## Long-term Vision

WaySense aims to become a comprehensive accessibility platform for public transportation, eventually:

- Supporting all major cities worldwide
- Providing real-time, AI-powered navigation
- Becoming the standard for transit accessibility information
- Integrating with autonomous vehicle systems for last-mile guidance
- Partnering with transit authorities for official accessibility data
